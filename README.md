# Performing Code
### Live Coding in Performative Contemporary Practices

**Artistic Research · 15 June – 17 August 2026 · Zürich, Switzerland**

[Website](https://computernoise.github.io/) · [GitHub Repository](https://github.com/computernoise/performing-code)

## About

*Performing Code – Live Coding in Performative Contemporary Practices* is an artistic research project exploring live coding as a compositional, performative, and computational practice.

The research investigates how code can function as expressive material in real-time sound generation, rhythmic organization, and audiovisual performance. It examines the relationships between algorithmic systems, human interaction, and emergent sonic structures, considering how computational processes can shape musical expression and performance.

The project combines practical experimentation, software development, critical reflection, and performance-based research.

## Research

The research focuses on the following areas:

- **Algorithmic composition** — Generative processes, mathematical operations, rhythmic systems, and transformations.
- **Rhythm and structure** — Relationships between repetition, variation, polyrhythm, complexity, and temporal organization.
- **Code as performance** — Real-time programming as an expressive practice in which code becomes part of the performance itself.
- **Human–machine interaction** — Interactions between performer, algorithmic system, and emergent sonic behavior.
- **Open-source tools** — Exploring accessible and adaptable software environments for creative coding and musical experimentation.
- **Performance contexts** — Rethinking the relationship between live coding, experimental music, audiovisual performance, and club culture.

## Methodology

The project develops through iterative cycles of coding, listening, experimentation, documentation, and performance.

Rather than treating algorithms exclusively as tools for producing predetermined musical results, the research explores how computational systems can generate unexpected relationships, unstable structures, and evolving rhythmic behaviors.

Practical investigations are documented through source code, technical notes, experiments, recordings, and reflections on the performative process.

## Tools and Environments

The research uses open-source and creative coding environments, including:

- [SuperCollider](https://supercollider.github.io/) — Algorithmic composition, synthesis, and real-time sound processing.
- [Pure Data](https://puredata.info/) — Visual programming for sound and interactive systems.
- [Strudel](https://strudel.cc/) — Browser-based live coding for algorithmic music.
- [Hydra](https://hydra.ojack.xyz/) — Live-coded visuals and audiovisual experimentation.
- [p5.js](https://p5js.org/) — Creative coding and visual systems.
- [Sonic Pi](https://sonic-pi.net/) — Live coding and algorithmic music.

These environments provide different approaches to real-time composition, system design, and performance.

## Project Context

**Performing Code – Live Coding in Performative Contemporary Practices** was developed at [Unsorted Space](https://unsorted.love/) in Zürich, Switzerland, from 15 June to 17 August 2026.

The project forms part of an ongoing artistic practice concerned with experimental music, computational systems, rhythm, and performative approaches to technology.
